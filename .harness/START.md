## 启动步骤

### Step 1: 确认需求

阅读并确认 `.harness/requirements.md` 中的需求是否完整。

**确认命令**:
```
请确认 requirements.md 中的需求是否完整，如有遗漏请补充。
```

### Step 2: 确认技术选型

阅读并确认 `.harness/tech-stack.md` 中的技术选型。

**确认命令**:
```
请确认 tech-stack.md 中的技术选型是否认可。
```

### Step 3: 确认任务列表

阅读并确认 `.harness/task.json` 中的任务列表。

**确认命令**:
```
请确认 task.json 中的任务列表是否完整、合理。
```

### Step 4: 完成依赖配置

按照 `.harness/dependencies.md` 中的说明完成配置。

**检查命令**:
```bash
flutter doctor -v
```

### Step 5: 启动自动执行

**方式一: 使用脚本** (Linux/macOS)
```bash
cd F:/opc/mysic
./.harness/run.sh
```

**方式二: 在 Claude Code 中执行**
```
请开始执行 .harness/task.json 中的任务。
使用 --dangerously-skip-permissions 模式自动执行所有操作。
```
