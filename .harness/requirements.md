# Mysic 音乐播放器 - 需求文档

> 创建时间: 2026-04-18
> 状态: 待确认

## 1. 项目背景

基于 `F:\opc\mysic\index.html` 的音乐播放器 UI 设计，开发一个跨平台的本地音乐播放器应用。

## 2. 核心需求

### 2.1 功能需求

#### FR-001: 音乐播放
- 支持播放本地音乐文件（MP3, FLAC, AAC, OGG）
- 支持播放/暂停/上一首/下一首控制
- 支持进度条拖动跳转
- 显示当前播放时间/总时长
- 支持后台播放
- 系统媒体控制集成（锁屏/通知栏控制）

#### FR-002: 专辑封面展示
- 圆形专辑封面展示
- 播放时有脉冲发光动画
- 支持从音乐文件提取封面
- 无封面时显示默认占位图

#### FR-003: 播放模式
- 顺序播放模式
- 随机播放模式
- 单曲循环模式
- 模式切换有视觉反馈

#### FR-004: 歌单管理
- 预置歌单：全部歌曲、我喜欢的、最近播放
- 支持创建自定义歌单
- 支持添加/移除歌曲到歌单
- 歌单数据本地持久化

#### FR-005: 本地音乐扫描
- 一键扫描全盘音乐文件
- 显示扫描进度
- 解析音乐元数据（标题、艺术家、专辑、时长）
- 扫描完成后显示歌曲数量

#### FR-006: 抽屉菜单
- 左侧滑出抽屉
- 显示播放模式选择
- 显示歌单列表
- 显示扫描全盘按钮
- 显示关于我们入口

#### FR-007: 添加到歌单
- 底部弹出面板
- 显示所有可用歌单
- 点击添加到指定歌单
- 显示添加成功提示

#### FR-008: 关于页面
- 显示应用 Logo 和名称
- 显示版本信息
- 显示 GitHub 链接
- 显示支持作者（二维码占位）

### 2.2 非功能需求

#### NFR-001: 性能
- 应用启动时间 < 2s
- 页面切换流畅 (60fps)
- 内存占用 < 150MB
- 音频播放无卡顿

#### NFR-002: 兼容性
- Android 5.0+ (API 21+)
- iOS 12.0+
- Windows 10+

#### NFR-003: 安全性
- 本地数据安全存储
- 权限最小化原则

## 3. UI 设计规范

### 3.1 颜色方案
| 名称 | 色值 | 用途 |
|------|------|------|
| Primary | #10b981 | 主要按钮、强调元素 |
| Surface | #18181b | 背景色 |
| Card | #27272a | 卡片背景 |
| Muted | #71717a | 次要文字 |
| White | #ffffff | 主要文字 |

### 3.2 字体
- 主字体: Inter
- 标题: 24px Bold
- 正文: 16px Regular
- 次要文字: 14px Regular

### 3.3 动画
- 过渡时长: 150-300ms
- 缓动曲线: cubic-bezier(0.4, 0, 0.2, 1)
- 播放动画: 3s pulse-glow
