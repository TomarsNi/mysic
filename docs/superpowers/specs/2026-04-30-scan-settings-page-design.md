# 扫描设置页面设计文档

## 概述

将扫描设置从底部弹框改为独立页面，并增加高级选项功能。

## 目标

- 提供更好的用户体验，独立页面比弹框有更多空间展示设置项
- 增加高级选项，让用户可以更精细地控制扫描行为

## 页面结构

### 1. 顶部标题栏

```
[<- 返回]     扫描设置
```

- 左侧：返回按钮
- 中间：标题 "扫描设置"

### 2. 扫描操作区

```
┌─────────────────────────────────┐
│         [开始扫描]              │
│    扫描中... 45%                │
│    ████████░░░░░░░░░░░░         │
└─────────────────────────────────┘
```

- 扫描按钮：渐变背景，点击开始扫描
- 扫描中：显示进度条和百分比
- 扫描完成：显示结果摘要

### 3. 扫描目录管理

```
扫描目录管理
仅扫描以下目录中的音乐文件

┌─────────────────────────────────┐
│ C:\Users\xxx\Music         [删除] │
│ D:\Music                   [删除] │
└─────────────────────────────────┘

[添加目录]  [恢复默认]
```

- 目录列表：显示当前配置的扫描目录
- 添加目录：弹出对话框输入路径
- 恢复默认：重置为系统默认音乐目录

### 4. 高级选项

```
高级选项

文件格式过滤
┌─────────────────────────────────┐
│ [✓] MP3    [✓] FLAC   [✓] WAV   │
│ [✓] M4A    [✓] OGG    [✓] AAC   │
│ [✓] WMA    [✓] APE             │
└─────────────────────────────────┘

最小文件大小
┌─────────────────────────────────┐
│ [100] KB                       │
│ 提示：过滤掉过小的音频文件        │
└─────────────────────────────────┘

自动去重
┌─────────────────────────────────┐
│ [✓] 启用                       │
│ 提示：扫描时自动跳过已存在的歌曲  │
└─────────────────────────────────┘
```

- 文件格式过滤：多选框，选择要扫描的音频格式
- 最小文件大小：输入框，单位 KB，默认 100KB
- 自动去重：开关，默认启用

## 数据存储

使用 SharedPreferences 存储高级选项：

| 键名 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `scan_audio_formats` | List<String> | `["mp3", "flac", "wav", "m4a", "ogg", "aac", "wma", "ape"]` | 要扫描的音频格式 |
| `scan_min_file_size_kb` | int | 100 | 最小文件大小（KB） |
| `scan_auto_dedupe` | bool | true | 是否自动去重 |
