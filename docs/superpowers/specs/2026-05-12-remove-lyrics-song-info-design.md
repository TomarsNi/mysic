# 歌词页面移除歌曲信息栏设计

## 目标

删除歌词页面 AppBar 下方的歌曲基础信息展示部分（`_buildSongInfoBar()`），为歌词区域释放更多空间。

## 当前结构

歌词页面 (`lyrics_page.dart`) 布局从上到下：
1. `_buildTopBar()` — 自定义顶部栏，含"正在播放"标签、歌曲标题、关闭/编辑按钮
2. `_buildSongInfoBar()` — 歌曲信息栏（待删除），含专辑封面 56x56、歌曲标题、歌手·专辑信息
3. 歌词列表区域
4. 底部播放控制

## 改动内容

1. **删除 `_buildSongInfoBar()` 方法** — 整个方法及其 Row 布局（专辑封面、标题、歌手·专辑）
2. **删除调用** — 在 `build()` 方法中移除 `_buildSongInfoBar()` 的引用
3. **清理边界** — 删除信息栏上方的 `Border(bottom: BorderSide(color: white.withOpacity(0.05)))` 分隔线

## 不改动

- 顶部栏保留"正在播放"标签和歌曲标题
- 歌手·专辑信息不保留（用户确认不需要）
- 底部播放控制不变
- 歌词列表不变

## 效果

歌词列表向上扩展约 88px（56px 封面 + 16px*2 上下 padding），获得更多展示空间。
