# 播放队列弹窗功能设计

## 概述

在首页右下角新增一个按钮，点击后以底部弹窗展示当前播放歌单的歌曲列表，用户可点击歌曲切换播放。

## 功能需求

### 用户故事
作为用户，我希望能够快速查看当前播放歌单中的所有歌曲，并能够直接点击切换播放，而不需要进入抽屉菜单重新选择歌单。

### 核心功能
1. 右下角显示一个按钮
2. 点击按钮弹出底部弹窗，展示当前播放队列
3. 弹窗标题显示当前歌单名称
4. 列表展示歌曲名称和艺术家
5. 当前播放歌曲高亮显示（accent 色文字 + 播放图标）
6. 点击歌曲切换播放

## UI 设计

### 按钮设计
- **位置**：首页右下角（`floatingActionButton`）
- **样式**：
  - 圆形按钮，直径 56px
  - 背景色：`#27272a`（card 色）
  - 图标：`Icons.queue_music_rounded`，白色，24px
  - 点击效果：ripple 动画

### 弹窗设计
参考设计稿 `index.html` 中的底部面板规范：

```
┌─────────────────────────────────────┐
│            ▓▓▓▓▓ (拖拽指示条)          │
│                                     │
│  本地音乐                           │  ← 标题（歌单名称）
│                                     │
│  ┌─────────────────────────────────┐│
│  │ 🔊 夜曲                    03:45 ││  ← 当前播放（高亮）
│  │    周杰伦                       ││
│  └─────────────────────────────────┘│
│  ┌─────────────────────────────────┐│
│  │     晴天                    04:12 ││  ← 普通歌曲
│  │    周杰伦                       ││
│  └─────────────────────────────────┘│
│  ...                                │
└─────────────────────────────────────┘
```

**样式规范**：
- 背景：`#27272a`（card 色）
- 顶部圆角：`rounded-t-3xl`（24px）
- 拖拽指示条：宽 40px，高 4px，灰色圆角
- 标题：18px，font-semibold，白色
- 歌曲项：
  - 歌曲名：14px，当前播放为 accent 色，其他为白色
  - 艺术家：12px，muted 色
  - 时长：12px，muted 色，右对齐
  - 播放图标：accent 色，仅当前播放歌曲显示

### 动画
- 弹窗进入：从底部滑入，300ms，`cubic-bezier(0.4, 0, 0.2, 1)`
- 遮罩层：淡入 250ms

## 技术设计

### 数据流
```
PlayerProvider
├── playlist: List<Song>      // 当前播放列表
├── currentIndex: int         // 当前播放索引
├── currentSong: Song?        // 当前歌曲
└── playSongAtIndex(index)    // 切换播放方法
```

### 文件结构
```
lib/
├── main.dart                           # 修改：添加 FAB
└── shared/
    └── widgets/
        └── playlist_queue_sheet.dart   # 新增：播放队列弹窗组件
```

### 组件设计

**PlaylistQueueSheet**（StatelessWidget）
- 输入参数：
  - `songs`: `List<Song>` — 歌曲列表
  - `currentIndex`: `int` — 当前播放索引
  - `playlistName`: `String` — 歌单名称
  - `onSongTap`: `void Function(int index)` — 歌曲点击回调

### 实现步骤
1. 创建 `PlaylistQueueSheet` 组件
2. 在 `main.dart` 中添加 `floatingActionButton`
3. 点击 FAB 时调用 `showModalBottomSheet` 展示弹窗
4. 从 `PlayerProvider` 获取数据并传入弹窗
