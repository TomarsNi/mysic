# UI 重构与播放功能修复设计

## 背景

当前 Flutter 实现与 index.html 设计稿不一致，且扫描后无法播放音乐。需要重构主页面布局并修复播放功能。

## 问题分析

### 问题 1：UI 与 index.html 不一致

| 项目 | index.html | 当前 Flutter |
|------|------------|--------------|
| 主页面 | 播放器页面 | 欢迎页面 |
| 专辑封面 | 圆形，有播放动画 | 圆角矩形 |
| 歌词预览 | 两行歌词，点击进入歌词页 | 占位文本 |
| 抽屉播放模式 | 有（顺序/随机/循环） | 无 |
| 扫描入口 | 抽屉底部 | 主页面中央 |

### 问题 2：扫描后无法播放

**根本原因：** `onPlaylistTap` 只调用了 `selectPlaylist`，没有：
1. 将歌曲设置到播放器
2. 开始播放

```dart
// 当前代码
onPlaylistTap: (playlist) {
  playlistProvider.selectPlaylist(playlistId);
  // 缺少：playerProvider.setPlaylist() 和 play()
}
```

### 3. 播放功能修复

**点击歌单流程：**

```
用户点击歌单
    ↓
获取歌单歌曲列表
    ↓
调用 playerProvider.setPlaylist(songs)
    ↓
调用 playerProvider.play()
    ↓
主页面 UI 自动更新（通过 Consumer 监听）
```

**代码修改：**

```dart
// main.dart - onPlaylistTap 回调
onPlaylistTap: (playlist) async {
  // 1. 选择歌单（加载歌曲）
  await playlistProvider.selectPlaylist(playlist.id!);

  // 2. 获取歌曲列表
  final songs = playlistProvider.selectedPlaylistSongs;

  if (songs.isNotEmpty) {
    // 3. 设置播放列表并播放
    await playerProvider.setPlaylist(songs);
    await playerProvider.play();
  }

  // 4. 关闭抽屉
  Navigator.of(context).pop();
}
```

## 实现步骤

1. **修改 `album_cover.dart`** — 改为圆形，添加播放动画
2. **修改 `play_controls.dart`** — 添加随机/循环按钮
3. **修改 `app_drawer.dart`** — 添加播放模式选择区
4. **重构 `main.dart` 主页面** — 采用播放器布局
5. **修复播放功能** — 修改 `onPlaylistTap` 回调
6. **测试验证** — 扫描 → 点击歌单 → 播放

## 验收标准

1. 主页面布局与 index.html 一致
2. 专辑封面为圆形，播放时有动画效果
3. 抽屉有播放模式选择（顺序/随机/循环）
4. 扫描后点击歌单能正常播放音乐
5. 播放控制（播放/暂停、上一首、下一首）正常工作
